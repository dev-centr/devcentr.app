# Site generation prompt for devcentr.app

Vision and content for the **DevCentr** flagship product marketing site.

## Context

- **Domain:** https://devcentr.app
- **Hosting:** GitHub Pages (static SolidStart build; custom domain)
- **Product:** Development Orchestration Suite (DOS) desktop app
- **Org site:** https://devcentr.org (movement / catalog — do not duplicate here)

## Design (do not regress)

- Cool steel neutrals + teal signal — **not** cream/serif/terracotta, **not** purple glass, **not** broadsheet rules, **not** Inter/blue SaaS cards
- Brand-first hero: wordmark **DevCentr** is the hero signal; one headline; one supporting sentence; CTA group; full-bleed orbital visual
- No cards in the hero
- Fonts: Space Grotesk + IBM Plex Mono
- Motion: orbit / reverse orbit / hub pulse
- No login

## Content pillars

1. Ecosystem Management — environment as code
2. Visual Blueprints — systems made visible
3. AI Synergy — context that compounds
4. Reproducible Workspaces — same story every machine
