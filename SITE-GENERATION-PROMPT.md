# Site generation prompt for devcentr.app

Vision and content for the **DevCentr** flagship product marketing site.

## Context

- **Domain:** https://devcentr.app
- **Hosting:** GitHub Pages (static SolidStart build; custom domain)
- **Product:** Development Orchestration Suite (DOS) desktop app
- **Org site:** https://devcentr.org — cultural resource / development path / “0 to pro” outcome (do not duplicate that pitch here)
- **This site owns:** category + mechanism (DOS, orchestration)

## Naming stance

- **Umbrella:** Development Orchestration Suite (DOS)—lead with this
- **DevOps:** One **facet** of the suite (CI/CD, infra, traditional ops). Name it in capabilities/body; do not lead the hero as “DevOps GUI.” Allude in literature to widen the concept over time.
- **“Dev OS”:** Mention once, lightly, as a casual mental model / association—not a public category or hero line. Avoid “X OS” fashion emphasis; DOS already carries the idea.

## Design (do not regress)

- Cool steel neutrals + teal signal — **not** cream/serif/terracotta, **not** purple glass, **not** broadsheet rules, **not** Inter/blue SaaS cards
- Brand-first hero: wordmark **DevCentr** is the hero signal; one headline; one supporting sentence; CTA group; full-bleed orbital visual
- No cards in the hero
- Fonts: Space Grotesk + IBM Plex Mono
- Motion: orbit / reverse orbit / hub pulse
- No login

## Messaging

1. **app hero (pitch):** “Stop managing tools. Orchestrate ecosystems.”
2. **app under-copy:** Flagship DOS for Windows, macOS, and Linux; DevOps is one facet; quiet “Dev OS” mental-model nod
3. **capabilities:** Include DevOps as a listed capability among ecosystem / visual / AI / reproducible workspaces
4. **org outcome pitch:** Lives on https://devcentr.org — not this hero
5. **Quiet footer claim:** “The first Development Orchestration Suite.”

## Content pillars

1. Ecosystem Management — environment as code
2. Visual Blueprints — systems made visible
3. AI Synergy — context that compounds
4. Reproducible Workspaces — same story along the path
5. DevOps — one facet (pipelines / infra / traditional ops)
