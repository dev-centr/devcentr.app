= devcentr.app

Application homepage and marketing site for Dev-Centr.

link:https://devcentr.app[Explore the site] ·
link:https://github.com/dev-centr/devcentr.app/issues[Report Bug] ·
link:https://github.com/dev-centr/devcentr.app/issues[Request Feature]

== About The Project

Product marketing site for the link:https://github.com/dev-centr/devcentr[DevCentr] Development Orchestration Suite (DOS).

=== Domain

* **URL:** link:https://devcentr.app[devcentr.app]
* **Hosting:** GitHub Pages (static SolidStart export)

== Built With

* link:https://start.solidjs.com/[SolidStart]
* Tailwind CSS v4 (steel/teal brand shared with link:https://devcentr.org[devcentr.org])
* link:https://pnpm.io/[pnpm]

== Getting Started

[source,bash]
----
pnpm install
pnpm dev
----

== Usage

[source,bash]
----
pnpm build
----

Static output lands in `.output/public` (deployed by GitHub Actions).
