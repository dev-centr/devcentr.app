== Getting Started

[source,bash]
----
pnpm install
pnpm dev
----

== Usage

[source,bash]
----
pnpm build
----

Static output lands in `.output/public` (deployed by GitHub Actions).

The homepage **Download** button prefers `DevCentr-windows-x64-setup.exe` from the latest GitHub release. The zip is offered as a **portable** link only.
