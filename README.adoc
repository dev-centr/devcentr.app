= devcentr.app

Product marketing site for the link:https://github.com/dev-centr/devcentr[DevCentr] Development Orchestration Suite (DOS).

== Domain

* **URL:** link:https://devcentr.app[devcentr.app]
* **Hosting:** GitHub Pages (static SolidStart export)

== Stack

* **Framework:** link:https://start.solidjs.com/[SolidStart]
* **Styling:** Tailwind CSS v4 (steel/teal brand shared with link:https://devcentr.org[devcentr.org])
* **Package manager:** pnpm

== Getting started

[source,bash]
----
pnpm install
pnpm dev
----

== Build

[source,bash]
----
pnpm build
----

Static output lands in `.output/public` (deployed by GitHub Actions).
